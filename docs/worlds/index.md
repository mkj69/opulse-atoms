## What the worlds are for { #what-the-worlds-are-for }

Each contract separates what the world gives from what a learner may invent. Exported towers contain recorded cases; the five-level ladder proposes harder cases.

The Build quickstart runs a core example, not a world export. The Computer design has a separate browser lab on Play.
