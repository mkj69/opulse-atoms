# Legacy-v1 runner

<span class="a2-badge a2-badge-legacy">Legacy-v1</span>

This runner executes the older operations-only dialect. It cannot check v2 definitions; ASCII labels on this page are display aliases for its old symbols. The runner downloads Pyodide when opened and decodes them before v1 execution.

<details class="a2-legacy-source">
<summary role="button">Open legacy-v1 source and runner</summary>
<p>Legacy-v1 source below displays ASCII labels for v1 symbols. Edit the labels in either field; they decode to v1 source for execution. This does not convert v1 semantics into v2 notation.</p>

Use the world selector, then choose a preset and run the expression. Its Steps panel shows v1 reductions; its Atoms tab edits v1 operations. See [Play / Lab](../) for the finite v2 computer preview.
