# obj_op

Idealized, deterministic second-resolution periodic scheduling (not live timetables).
The world opens **objects and operations only**. Its eight-layer story builds
canonical cycles, non-coprime CRT joins, plans, compiled windows, and merged
blackouts. Layer-zero hosts handle bounded arithmetic and raw carrier field reads;
each invented object carries written validity and canonicalization nodes rather than
object-specific host rules. The inventions run through the Opulse written -> checked -> callable -> verified ->
promoted pipeline. Verification covers stated finite witnesses, not a universal proof.

Rebuild the tagged catalogue export with
`PYTHONPATH=src python3 -m opulse.worlds_v2.obj_op.export`, refresh the
catalogue index with `PYTHONPATH=src python3 -m opulse.worlds_v2.index`, and run
`PYTHONPATH=src python3 -m pytest tests/worlds_v2/obj_op`.
