# Dice depth world, version 1

## Layer zero

The domain givens are weighted `Die` rolls, `pure`, bounded `jump`, exact `mass`, and a public `bind` kernel unfolding with measured recursion. `Fair` weighs every face once; `Tilt` weighs faces `(1,1,1,1,2,6)`. `Dist` canonicalizes finite rational weights and `State<position,die>` carries the *same* hidden die through every turn. The generic hosts are `pair`, `state`, `die`, `event`, `belief`, `walk`, `make_entry`, `make_dist` (constructors), `entries`, `item`, `weight`, `field`, `nth` (accessors), `equal`, `intersect` (structural equality and generic event intersection), `add`, `subtract`, `multiply`, `divide`, `int_add`, `int_sub`, `int_mul_fraction`, `less_equal` (small exact arithmetic), and `replace_at`, `is_empty`, `head`, `tail`, `cons`, `length` (finite list primitives). These are reusable structure operations, not hidden story-card computations. `event`, `belief` and `walk` build raw cards; only invented `Event`, `Belief` and `Walk` enforce their refinements. `to_card`/`from_card` bijectively convert canonical rational values.

## Tower and evidence

The export retains conceptual design layers `1..12`; `def_layer` records actual kernel dependencies, with no padding. Every scope below is run through the reference and kernel; object scopes also pass the core canon obligations. Example steps are generated in the export directly from the example expression and its kernel trace.

The promoted `step` operation is also checked on 100 cases: two priors x goals `2..6` x both hidden-die indices x every position `0..goal`. Card 10 uses the layer-zero parameterized `step_with` transition, not the preceding `step` card, so its honest `def_layer` is 3. `advance` plugs the three operation slots into this transition; its evidence includes one alias substitution in each slot, checked against the reference and unfolded trace. The larger `advance`/`hit_prob` export examples run three/eight turns respectively and are explicitly included in their evidence alongside the small-turn families; the exact showcase fractions are independently checked by the reference design. Tower values stay exact; edge-entry checks increase six example step counts as shown above. `OPULSE_RUN_SLOW=1` also checks two independent full exports; the default suite builds the first three cards afresh and shares one full pipeline build per process.

`Event.make`, `Belief.make`, and `Walk.make` are generated by core `ObjectSpec(refine)`; malformed range, prior, and goal bases return `Bottom(invalid)`. Canonicalization is the identity on already-canonical base values, tested by core for totality, idempotence, and preservation of validity. Downstream cards use generated `.base` operations, and `update` uses `Belief.make`. `mean` folds the entries of its explicit distribution argument, including scores outside `2..12`; it has no hidden truth input. The `conditional` failure example returns `Bottom(domain)` for zero evidence and includes a real kernel trace. No private judge inputs are exported.

## Deviations and adapters

- The original design's conceptual layer numbers express a teaching order, not dependencies. The computed layers are lower where a card does not actually call the preceding card (for example `mean` and `hitting`). `mean` now folds the actual distribution entries rather than assuming a score cutoff at 12.
- `pair_one`, `pair_with`, `score_one`, and `first_score` are kernel definitions, not host shortcuts. They make operation-slot arguments real `FnRef`s and expose a second scoring operation and a second die-to-distribution operation in the verified families.
- `DiceLibrary._params` supplies the observation parameter names expected by the generic kernel; `DiceLibrary.scope` adds the given `bind` unfolding and generic continuations. The core scope cache avoids reconstructing generated object operations on each bounded case. `run_example` evaluates nested showcase expressions through the learner `Library.run` guard with a temporary layer-zero expression wrapper and retains the real child trace. There is no custom dependency hash or FnRef JSON shim.
- Declared `die` and `dist` are given sorts because their layer-zero constructors return cards of those sorts, not `Refine<value>` wrappers; generated refinement edge guards reject ordinary rolls and distributions. Their hosts still validate and normalize exact values. The `event`, `belief`, and `walk` hosts check raw structure, not invented interval/prior/goal bounds. Invented `Event`, `Belief`, and `Walk` use raw base sorts matching their actual cards rather than the unrelated given `value` sort.
- `adapter.check_generic` suppresses static card-sort false positives and unresolved **generated** object calls; `conditional` now uses core `Library.check`. `adapter.check_refs` additionally validates FnRef resolution. `adapter.check_local`/`make_callable_local` are required for non-robot observations receiving explicit inputs. `adapter.verify_general` checks reference, inline unfolding, unchanged inputs, and repeated probe outcomes, and binds the digest of the checked domain. Invented objects, operations, and `independent` use core `Library.verify` directly. `score` retains local verification because core rejects forwarding its operation slot as a `bind` context (`operation parameter f cannot be stored as data`); `advance` uses correlated one-at-a-time alias substitutions that the core Cartesian family verifier cannot express.
- Exact Gauss-Jordan elimination runs inside `hitting`'s measured kernel recursion, never as a host Gaussian-elimination function. The existing measured `Rec` handles the turn recursion, so no spec-0.3 extension is required.

## Core issues

The export preserves the design prose in `design_decl` and the computed `def_layer`. Only `mean` can round-trip from its stored body through `notation.print_definition`; the other eleven have no `decl`/`ascii`. No hand-written signatures or replacement bodies are published. The stored definitions and evidence remain unchanged.

Printer unavailable: `independent`, `Event`, `score`, `Belief` — ValueError: dependencies cannot be represented in their current order; `total` — ValueError: operation metadata has no compact ASCII declaration; `conditional`, `update`, `Walk`, `advance`, `hit_prob`, `hitting` — ValueError: invalid ASCII identifier.

The `total`, `update`, `hit_prob`, and `hitting` example texts parse to exactly the evaluated nodes. The following nine examples retain their original display text and have no `ascii` field: `independent` (operation references and `?mass` require context), `Event` and `Belief` (generated `.make` call syntax), `conditional` (both success and domain-failure inputs include `weighted.entry` cards, whose `entry` tag is reserved), `score` and `mean` (the same `weighted.entry` tag), `Walk` (generated `.base` and `.make` calls), and `advance` (operation references and `?mass` require context). The parser rejects these texts without a context or, for `weighted.entry` and generated calls, even with one; expressing the literal evaluated nodes in the current grammar is not possible. Their values, steps, traces and evidence remain unchanged.

Minimal checker repro: writing `ObjectSpec("Event", "refine", base="event", valid=Case(Test(Call("less_equal", (Lit(2), Call("field", (Var("x"), Lit(0))))), Lit(True)), canon=Var("x"))` and calling `Library.check("Event")` reports `less_equal argument 2: expected int, got value` even though valid interval values pass the kernel and core object verification. An operation reading a given `state` through generic `field` similarly reports `field argument 1: expected value, got state`. `Library.check("independent")` on `Call("bind", (Call("f", ...), Lit(FnRef("pair_with")), ...))` reports `operation references cannot be stored as data`. Non-robot observations such as `hit_prob` call lower invented operations on an explicit distribution; the default robot observation checker treats those as reads of sealed truth. These local adapters remain until type checking and non-robot observations support these patterns.

## Validation

`test_wv2_dice_depth.py` imports the standalone catalogue implementation with `importlib`, cross-checks all twelve exact design values and the published showcase outcomes, verifies real bounded/exhaustive scopes and object canon obligations, checks inline/boundary step accounting and unchanged probe truth, and compares the committed export to a fresh `build_export()`. The optional slow tests compare another fresh full export to the committed artifact and test independent export state. The dice declaration is locked in isolation and the shared declaration validator is run without regenerating the index.
